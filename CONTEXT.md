# Terra

A collaborative team retrospective board application.

## Language

**Board**:
A collaborative workspace for conducting a team retrospective.
_Avoid_: Workspace, Session, Project

**Column**:
A vertical grouping within a Board representing a specific category or stage of the retrospective (e.g., "Went well", "Needs improvement").
_Avoid_: List, Category, Bucket

**Card**:
An individual piece of feedback or note placed within a Column by a participant.
_Avoid_: Note, Item, Ticket

**Short Code**:
A temporary, unique 6-character identifier used to generate shareable links for joining a Board securely.
_Avoid_: Join code, Share code, Link code
